    25→## Overview
    26→
    27→This document outlines the rollback procedures for Phase 8 of AlgeriaTrade.dz, which introduced 12 new features including multi-provider payments, ERP integration, AR viewer enhancements, CRM pipeline, WebRTC video calls, and currency exchange support.
    28→
    29→### Scope of Phase 8 Changes
    30→
    31→| Feature Area | Components | Risk Level |
    32→|--------------|------------|------------|
    33→| Payment System | SATIM, Stripe, Crypto payments | **HIGH** |
    34→| ERP Integration | SAP/Odoo connectors | MEDIUM |
    35→| AR Viewer | Model optimizer, USDZ generation | LOW |
    36→| CRM Pipeline | Deals, stages, analytics | MEDIUM |
    37→| Video Calls | WebRTC signaling server | LOW |
    38→| Currency Exchange | Multi-currency support | MEDIUM |
    39→
    40→### Rollback Objectives
    41→
    42→1. Restore system stability within **15 minutes** of triggering
    43→2. Ensure **zero data loss** for existing transactions
    44→3. Maintain availability of core platform features
    45→4. Provide clear communication to all stakeholders

    64→    
    65→  payment_failure_spike:
    66→    condition: "Payment failure rate > 10% in 10 minutes"

    70→    condition: "DB connection errors > 20% for 2 minutes"

    74→### Manual Triggers
    75→
    76→Manual rollback should be initiated when:
    77→
    78→- [ ] Critical security vulnerability discovered
    79→- [ ] Data corruption detected
    80→- [ ] Payment processing errors causing financial discrepancies
    81→- [ ] Customer complaints exceeding normal threshold (50+ in 1 hour)
    82→- [ ] Third-party service (SATIM/Stripe/SAP) integration issues
    83→- [ ] Performance degradation > 200% baseline

   158→## Database Rollback Procedure
   159→
   160→### Option A: Full Database Restore (Recommended for Data Corruption)
   161→
   162→**Time Estimate:** 5-10 minutes  
   163→**Data Loss Risk:** Transactions since backup will be lost (requires reconciliation)
   164→
   165→#### Steps:
   166→
   167→```bash
   168→# 1. Identify latest pre-deployment backup
   169→ls -lt backups/ | head -5
   170→
   171→# 2. Stop application to prevent new writes
   172→docker compose -f docker-compose.production.yml stop app worker
   173→
   174→# 3. Create emergency post-failure backup (for analysis)
   175→pg_dump $DATABASE_URL > backups/emergency_pre_rollback_$(date +%Y%m%d_%H%M%S).sql
   176→
   177→# 4. Restore from backup
   178→gunzip -c backups/phase8_pre_migration_YYYYMMDD_HHMMSS.sql.gz | psql $DATABASE_URL
   179→
   180→# 5. Verify restore integrity
   181→psql $DATABASE_URL -c "\dt"  # List tables
   182→psql $DATABASE_URL -c "SELECT COUNT(*) FROM \"User\";"  # Verify row counts
   183→
   184→# 6. Restart services
   185→docker compose -f docker-compose.production.yml start app worker
   186→```
   187→
   188→### Option B: Migration Rollback (Recommended for Schema Issues)
   189→
   190→**Time Estimate:** 3-5 minutes  
   191→**Data Loss Risk:** Minimal if no data written to new tables
   192→
   193→#### Steps:
   194→
   195→```bash
   196→# 1. Check migration history
   197→cd /path/to/deployment
   198→bunx prisma migrate status
   199→
   200→# 2. Roll back last migration
   201→bunx prisma migrate resolve --rolled-back "phase8-production-MIGRATION_ID"
   202→
   203→# 3. If needed, manually drop Phase 8 tables (DANGEROUS)
   204→psql $DATABASE_URL << 'SQL'
   205→-- Only run if absolutely necessary!
   206→DROP TABLE IF EXISTS "CryptoTransaction" CASCADE;
   207→DROP TABLE IF EXISTS "ERPSyncLog" CASCADE;
   208→DROP TABLE IF EXISTS "ARModel" CASCADE;
   209→DROP TABLE IF EXISTS "CRMDeal" CASCADE;
   210→DROP TABLE IF EXISTS "PipelineStage" CASCADE;
   211→DROP TABLE IF EXISTS "Invoice" CASCADE;
   212→DROP TABLE IF EXISTS "CurrencyRate" CASCADE;
   213→-- Keep TvaRate, Currency, PaymentProvider as they may have data dependencies
   214→SQL
   215→
   216→# 4. Restart application
   217→docker compose -f docker-compose.production.yml restart app
   218→```

   229→## Feature Flags for Safe Disable
   230→
   231→Phase 8 features are controlled via Redis-based feature flags that can be toggled without redeployment or downtime.
   232→
   233→### Available Feature Flags
   234→
   235→| Flag Key | Default | Description |
   236→|----------|---------|-------------|
   237→| `feature:multi_provider_payments` | true | Enable SATIM/Stripe/Crypto payments |
   238→| `feature:satim_payments` | true | Enable SATIM specifically |
   239→| `feature:stripe_payments` | true | Enable Stripe specifically |
   240→| `feature:crypto_payments` | true | Enable cryptocurrency payments |
   241→| `feature:erp_integration` | true | Enable ERP connectors |
   242→| `feature:ar_viewer_enhanced` | true | Enable AR model optimization |
   243→| `feature:crm_pipeline_v2` | true | Enable CRM pipeline features |
   244→| `feature:webrtc_video_calls` | true | Enable video calling |
   245→| `feature:currency_exchange` | true | Enable multi-currency display |
   246→| `feature:invoicing_module` | true | Enable invoice generation |
   247→
   248→### Quick Disable Commands
   249→
   250→```bash
   251→#!/bin/bash
   252→# Phase 8 Feature Flag Emergency Disable Script
   253→
   254→REDIS_CLI="redis-cli -u ${REDIS_URL:-redis://localhost:6379}"
   255→
   256→# Disable ALL Phase 8 features at once
   257→disable_all_phase8_features() {
   258→    echo "Disabling all Phase 8 features..."
   259→    
   260→    $REDIS_CLI SET feature:multi_provider_payments "false" EX 3600
   261→    $REDIS_CLI SET feature:satim_payments "false" EX 3600
   262→    $REDIS_CLI SET feature:stripe_payments "false" EX 3600
   263→    $REDIS_CLI SET feature:crypto_payments "false" EX 3600
   264→    $REDIS_CLI SET feature:erp_integration "false" EX 3600
   265→    $REDIS_CLI SET feature:ar_viewer_enhanced "false" EX 3600
   266→    $REDIS_CLI SET feature:crm_pipeline_v2 "false" EX 3600
   267→    $REDIS_CLI SET feature:webrtc_video_calls "false" EX 3600
   268→    $REDIS_CLI SET feature:currency_exchange "false" EX 3600
   269→    $REDIS_CLI SET feature:invoicing_module "false" EX 3600
   270→    
   271→    # Clear cache to ensure flags take effect immediately
   272→    $REDIS_CLI DEL "cache:feature_flags"
   273→    
   274→    echo "All Phase 8 features disabled (1 hour TTL)"
   275→}
   276→
   277→# Disable specific feature category
   278→disable_payment_features() {
   279→    echo "Disabling payment features only..."
   280→    $REDIS_CLI SET feature:multi_provider_payments "false" EX 3600
   281→    $REDIS_CLI SET feature:satim_payments "false" EX 3600
   282→    $REDIS_CLI SET feature:crypto_payments "false" EX 3600
   283→    $REDIS_CLI DEL "cache:feature_flags"
   284→    echo "Payment features disabled"
   285→}
   286→
   287→# Re-enable features (after fix)
   288→enable_all_phase8_features() {
   289→    echo "Re-enabling all Phase 8 features..."
   290→    
   291→    $REDIS_CLI DEL feature:multi_provider_payments
   292→    $REDIS_CLI DEL feature:satim_payments
   293→    $REDIS_CLI DEL feature:stripe_payments
   294→    $REDIS_CLI DEL feature:crypto_payments
   295→    $REDIS_CLI DEL feature:erp_integration
   296→    $REDIS_CLI DEL feature:ar_viewer_enhanced
   297→    $REDIS_CLI DEL feature:crm_pipeline_v2
   298→    $REDIS_CLI DEL feature:webrtc_video_calls
   299→    $REDIS_CLI DEL feature:currency_exchange
   300→    $REDIS_CLI DEL feature:invoicing_module
   301→    $REDIS_CLI DEL "cache:feature_flags"
   302→    
   303→    echo "All Phase 8 features re-enabled"
   304→}
   305→
   306→# Usage based on argument
   307→case "${1:-}" in
   308→    --all)       disable_all_phase8_features ;;
   309→    --payments)  disable_payment_features ;;
   310→    --enable)    enable_all_phase8_features ;;
   311→    --status)    
   312→        echo "Current Phase 8 Feature Flag Status:"
   313→        $REDIS_CLI MGET \
   314→            feature:multi_provider_payments \
   315→            feature:satim_payments \
   316→            feature:crypto_payments \
   317→            feature:erp_integration \
   318→            feature:ar_viewer_enhanced \
   319→            feature:crm_pipeline_v2 \
   320→            feature:webrtc_video_calls \
   321→            feature:currency_exchange \
   322→            feature:invoicing_module
   323→        ;;
   324→    *)          echo "Usage: $0 [--all|--payments|--enable|--status]" ;;
   325→esac
   326→```

   348→┌─────────────────────────────────────────────────────────────┐
   349→│                    SHUTDOWN SEQUENCE                         │

   352→│  Step 1 (T-0:00)  ──►  Stop AR Model Processor              │

   408→

   443→docker compose $COMPOSE_FILES rm -f \

   446→    erp-sync-scheduler \
   447→    currency-refresher \
   448→    invoice-worker \

   478→echo "  - erp-sync-scheduler"
   479→echo "  - currency-refresher"
   480→echo "  - invoice-worker"
   481→echo "  - ar-model-processor"
